# Orange Cat Core

## 目录结构

```bash
core/
├── canvas/                      # 画布核心模块
│   ├── fabric-render.ts         # Fabric.js 渲染核心模块
│   ├── config.ts                # 配置文件，用于存放默认配置参数
│   ├── events.ts                # 事件模块，管理 Fabric.js 默认和自定义事件
│   └── utils/                   # 工具函数模块
│       └── debounce.ts          # 防抖函数
├── index.ts                     # 核心模块入口，统一导出核心功能
```

## 模块功能

`orange-cat/core` 是一个基于 Fabric.js 的高性能画布管理模块，封装了常见的画布操作、配置管理和事件监听，旨在提高使用 Fabric.js 开发的效率和代码可维护性。

### **主要模块**

#### **1. canvas/**

- **fabric-render.ts**

  - 提供核心的 Fabric.js 画布管理功能，包括画布初始化、对象添加、事件绑定、拖拽与缩放支持。
  - 支持自适应外部容器尺寸，动态调整画布大小。
  - 提供资源清理机制，适用于复杂应用场景。

- **config.ts**

  - 用于存储模块默认配置，例如缩放范围（`ZOOM_RANGE`）等常量。
  - 便于集中管理和统一修改配置参数。

- **events.ts**

  - 封装 Fabric.js 常用的事件监听逻辑，包括：
    - 滚轮缩放
    - 拖拽画布
    - 对象移动
    - 鼠标点击等
  - 支持扩展和自定义监听事件。

- **utils/debounce.ts**
  - 提供通用的防抖函数，用于优化性能，避免高频触发的事件（如 `resize` 和 `mouse:move`）引发性能问题。

#### **2. index.ts**

- 统一导出 `canvas` 模块中的核心功能。
- 提供模块的唯一入口，便于在外部引入。

## 模块特性

### **1. 灵活配置**

- 支持通过 `config.ts` 自定义模块默认配置。
- 用户可以覆盖默认配置，实现个性化调整。

### **2. 高度模块化**

- 事件处理、工具函数与核心逻辑分离，代码结构清晰，便于维护与扩展。
- 所有功能都可以按需引入，避免不必要的代码加载。

### **3. 丰富的事件支持**

- 内置 Fabric.js 常用事件，例如滚轮缩放和画布拖拽。
- 提供事件扩展接口，用户可添加自定义事件监听器。

### **4. 性能优化**

- 通过防抖和事件管理优化高频事件处理，提升渲染性能。
- 支持资源释放与事件解绑，避免内存泄漏。

### **5. 容器自适应**

- 支持动态调整画布尺寸，自动适应外部容器大小变化。
- 可选启用 `ResizeObserver` 或全局 `resize` 事件监听。

## 使用方法

### **安装**

确保依赖了 `fabric` 和 `orange-cat` 模块：

```bash
npm install fabric orange-cat
```
